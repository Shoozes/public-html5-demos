# Round 5A Rubric

Score the three axes independently. Hard-gate failure cannot be rescued by visual or workflow points.

## Hard gates

| Gate | Requirement |
| --- | --- |
| Artifact | `submission/index.html` is one complete HTML document at the canonical path. |
| Parse | Inline module JavaScript parses without manual repair. |
| Bootstrap | Pinned imports resolve and awaited `WebGPURenderer.init()` completes. |
| First frame | Player, dark-space background, and a landmark render without an error overlay. |
| Behavior | Every frozen Round 4 browser scenario and invariant passes. |
| Evidence | Required contract, ledger, review, decision, and before/after files exist. |
| Integrity | Reference, harness, skill, and rubric checksums remain unchanged. |

## Functional correctness: 100 points

| Area | Points |
| --- | ---: |

| **Total** | **100** |

Passing threshold: **90/100**, with every hard gate satisfied.

## Frozen budgets

- Wall time: 60 minutes per arm.
- Visual repair cycles: at most three per checkpoint and twelve overall.
- Functional repair cycles: at most eight after the first functional harness run.
- No informal extension after a budget expires.

Report all three scores and the hard-gate result separately before discussing a winner.
