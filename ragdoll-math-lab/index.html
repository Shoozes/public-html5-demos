Manual solver diagnostics

Each selected bone is a lightweight capsule rigid body. Sequential joint passes solve anchor error and fixed or hinged orientation before finite-stage contact projection.

velocity += gravity * dt position += velocity * dt orientation += angularVelocity * dt
anchorError = childAnchorWorld - parentAnchorWorld parent.position += anchorError * parentWeight child.position -= anchorError * childWeight

The lowest endpoint of each rotated capsule is projected above the arena plane. That contact point also supplies a bounded rotational correction.
