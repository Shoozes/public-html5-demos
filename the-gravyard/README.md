# The Gravyard

Retired demos preserved for reference. `the-gravyard` is the repository's chosen
archive folder name. Entries remain runnable where their original dependencies
work, but they are not promoted as active projects.

| Project | Archived | Status |
| --- | --- | --- |
| [Anthrocybernetics](anthrocybernetics/index.html) | 2026-09-25 | Removed from active gallery; implementation preserved unchanged |

For an archive move, preserve the source and useful evidence, record the new
owner here, remove active gallery promotion, and maintain existing public entry
URLs through the compatibility-route generator. Do not use archival work as an
implicit input to an unrelated benchmark or active project.

Optional archived interaction checks: `node tests/site-browser.mjs --include-archive`.
Default site browser checks cover the active gallery and experiment Flight Log.
